# JLayer

`jlayer-1.0.1.jar` decodifica os arquivos MP3 usados pela versão desktop.

- Projeto: [JavaZoom JLayer](http://www.javazoom.net/javalayer/javalayer.html)
- Artefato: `javazoom:jlayer:1.0.1` do Maven Central
- Licença declarada no POM do artefato: GNU Lesser General Public License (LGPL)

O JAR e as classes extraídas estão incluídos no repositório. Os iniciadores copiam as classes para `out/`, permitindo iniciar o jogo sem baixar dependências.
